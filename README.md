🌱 Smart Irrigation System
📌 Overview

A simple AI-based mini project that decides whether crops need watering using decision tree logic with thresholds (alpha & beta).

⚙️ Technologies
Python
Tkinter (GUI)
Random module

🧠 Working
Input: Soil moisture & sunlight (simulated)
If moisture < α → Water Needed 💧
Else if sunlight > β → Water Needed 💧
Else → No Water Needed ❌

🚀 How to Run
Save code as irrigation.py
Run: python irrigation.py
Enter α and β
Click Check Irrigation

📊 Features
GUI-based system
Real-time sensor simulation
Instant decision output

🔮 Future Scope
IoT sensor integration
Mobile app
Automated water control

👨‍💻 Conclusion
Demonstrates how basic AI can be used for smart farming and water management.
